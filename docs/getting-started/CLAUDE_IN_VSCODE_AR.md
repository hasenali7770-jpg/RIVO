# ربط Claude بـ Visual Studio Code

الآن أنا أشتغل بحاوية معزولة على السحابة (Claude Code on the web) — أعدّل الكود
وأدفعه إلى GitHub، لكن **ما عندي أي وصول لجهازك**. لذلك ما أكدر أنصّب شيئاً عندك
ولا أشغّل أمراً على حاسبتك.

الحل: تنصّب Claude Code داخل VS Code عندك، وساعتها يشتغل مباشرة على ملفاتك.

---

## ١. المتطلّبات

| | |
|---|---|
| VS Code | الإصدار 1.94.0 أو أحدث |
| حساب | أي اشتراك Claude مدفوع (Pro أو Max أو Team أو Enterprise) أو حساب Claude Console |

**ما تحتاج مفتاح API.** تسجّل الدخول بحسابك نفسه.

## ٢. نصّب الإضافة

افتح VS Code ← **`Ctrl+Shift+X`** ← ابحث عن **Claude Code** ← **Install**

> إذا ما ظهرت بعد التنصيب: `Ctrl+Shift+P` ← **Developer: Reload Window**

## ٣. افتحها وسجّل الدخول

افتح أي ملف، وراح تشوف **أيقونة الشرارة ✱** بأعلى يمين المحرّر — اضغطها.

أو: **`Ctrl+Shift+P`** ← اكتب `Claude Code` ← اختر **Open in New Tab**

أول مرّة تفتحها راح تظهر شاشة تسجيل الدخول — اضغط **Sign in** وأكمل من المتصفّح.

## ٤. اختصارات تفيدك

| | |
|---|---|
| `Ctrl+Esc` | التنقّل بين المحرّر وصندوق المحادثة |
| `Alt+K` | إدراج إشارة للملف والأسطر المحدّدة (مثل `@app.ts#5-10`) |
| `Ctrl+Alt+F` | إخفاء أو إظهار تفاصيل الأدوات بالمحادثة |

النص اللي تحدّده بالمحرّر يشوفه Claude تلقائياً — بدون ما تنسخه.

> **على ماك:** إذا `Cmd+Esc` ما اشتغل، النظام يحجزه لـGame Overlay.
> System Settings ← Keyboard ← Keyboard Shortcuts ← Game Controllers ← ألغِ التعليم.

## ٦. مهم: كل الشغل موجود بالمستودع

المشروع فيه ملف **`CLAUDE.md`** بالجذر، وهو أول شي يقرأه Claude لما يفتح المشروع.
فيه:

- القواعد اللي ما تنكسر (٨–١٨ صورة، ١٠٨٠p، ٣٬٠٠٠ دينار)
- الأوامر الجاهزة
- الفخّان الخطران: **لا تشغّل `prisma migrate dev` أبداً**، و**`test:e2e` يحذف كل الصفوف**
- بنية المشروع والاتفاقيات

يعني أي جلسة جديدة تبدأ وهي فاهمة المشروع، مو من الصفر.

**للاستمرار من هنا مباشرة**، اكتب له مثلاً:

```
اقرأ CLAUDE.md و HANDOVER.md، ثم شغّل ./infra/scripts/status.sh وقل لي وين وصلنا.
```

## ما الفرق بيني الآن وبين Claude عندك؟

| | أنا الآن (السحابة) | Claude عندك (VS Code) |
|---|---|---|
| يوصل لملفاتك | ✗ | ✓ |
| يشغّل أوامر على جهازك | ✗ | ✓ |
| يشوف تطبيق فلاتر على جهازك | ✗ | ✓ |
| يعدّل ويدفع إلى GitHub | ✓ | ✓ |
| يشتغل وأنت مسكّر الحاسبة | ✓ | ✗ |

**الاثنان يشتغلان على نفس المستودع.** أنا أدفع، وأنت تسحب بـ`git pull`، والعكس.
ما فيه تعارض ما دام كل واحد يدفع تعديلاته.

أنا أعدّل وأدفع إلى GitHub، وأنت تسحب بـ`git pull` وتشغّل
`./infra/scripts/setup.sh` عندك.
